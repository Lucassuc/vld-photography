Instead of capturing a new photo, I chose to edit an image I had captured before, as editing is also important in photography because sometimes there is beautiful lighting, but the background is noisy. So we need to learn how to edit the image. In this photograph, I removed the person behind the tree because I thought it made the image look untidy. This also made it much simpler and more visually appealing, something I hadn't noticed before — small details can change a lot.
